# Emberwake

Use British English. Keep the game dependency-free, static and compatible with GitHub Pages project paths. Preserve browser-local saves and the quiet, unhurried tone. Art is drawn directly in Canvas; avoid external asset, font or analytics requests.

Run `git pull` before inspecting an existing checkout. Run `npm test` for changes to state, progression, save handling or collision geometry. Check character creation, keyboard play and any changed modal in a browser. Update the README when scope or controls change. Do not add a paid service or account requirement.

Keep the public README spoiler-free: describe the premise, mood, features and controls, without revealing plot outcomes or character backstories.

Keep essential quest context and instructions in the journal as well as dialogue. Include the reason for the task, required quantities, destination and interaction key where relevant, so progress does not depend on remembering a conversation.

Use the shared `unknown` portrait for unidentified voices. Keep their appearance and location unrevealed until the story establishes them; narration and object interactions do not need a speaker portrait.

Keep changes local and uncommitted. Commit, push or publish only when the user explicitly requests it.
